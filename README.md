# cpu-design-project
Learning digital design and computer architecture through a step-by-step SystemVerilog CPU implementation, from logic gates to a simple processor.


Custom 16-Bit CPU & Assembler | SystemVerilog, Python

Designed a custom 16-bit instruction set architecture (ISA) combining RISC-V and LC-3 concepts, implementing 30+ arithmetic, logic, memory, branch, and control instructions using compact instruction encodings.
Implemented a multi-cycle processor in SystemVerilog featuring an ALU, register file, instruction decoder, unified memory, compare unit, and finite-state control unit to execute complete assembly programs.
Developed a two-pass Python assembler supporting labels, symbol-table generation, instruction validation, and machine-code generation for seamless software execution on the custom processor.
